# Final development run

[Back to the concepts](README.md) · [glossary](../glossary.md)

**What it means.** A last free run of a frozen strategy on development seeds no hypothesis has read, to catch a result that depended on the seeds used to choose and confirm it.

**Why it exists.** It is not a test: those seeds are development data. It guards the spend on the fresh test seeds.

**Example.** WP1.0 passed its confirm and missed this run, so it was not taken to the paid test.

**Where to find it.** [process](../process.md), [WP1.0 result](../wp10_final_dev.md)
