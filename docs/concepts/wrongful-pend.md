# Wrongful pend

[Back to the concepts](README.md) · [glossary](../glossary.md)

**What it means.** Pending a claim whose billed level the chart supports (or that was underbilled).

**Why it exists.** It is the main cost of being too cautious, counted per 1,000 claims beside the score.

**Example.** A 99214 claim from a busy but honest clinician is pended; the chart supports 99214.

**Where to find it.** [score P1.0](../score_prepay.md)
