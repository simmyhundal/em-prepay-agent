# Workflow and agent

[Back to the concepts](README.md) · [glossary](../glossary.md)

**What it means.** Two designs of the same system: in a workflow, code fixes the order of steps; in an agent, a language model chooses the steps within caps.

**Why it exists.** The project asks whether the model's freedom beats fixed steps, at what cost.

**Example.** WP1.0 is a workflow (no model calls); AP1.0 is the agent that mirrors it.

**Where to find it.** [glossary](../glossary.md), `src/wp10.py`, `src/ap10.py`
