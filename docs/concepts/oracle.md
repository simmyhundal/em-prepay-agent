# Oracle

[Back to the concepts](README.md) · [glossary](../glossary.md)

**What it means.** The best conceivable strategy under the same score and costs, built by reading the answer key; an upper bound, not a competitor.

**Why it exists.** It says how much money was available to catch, so a result can be read as a share of the possible.

**Example.** The oracle pends only claims whose pend adds to the score; on ten development seeds it earns about $1.0 million.

**Where to find it.** `eval/prepay_oracle.py`, [reference arms](../prepay_reference_arms.md)
